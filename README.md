- GitHub Pages for hosting

## Run it locally

1. Install [Quarto](https://quarto.org/docs/get-started/).
2. Clone the repository:

   ```bash
   git clone https://github.com/hlan22/YOUR-REPO-NAME.git
   cd YOUR-REPO-NAME
   ```

3. Preview the site:

   ```bash
   quarto preview
   ```

4. Render it for publishing:

   ```bash
   quarto render
   ```

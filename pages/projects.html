FlashApp: Flashcards That Plan Your ReviewsA flashcard study app with deck management, a practice mode with self-rated answers, and a review mode that uses a statistical model of recall to choose what to study next.Engineering · Flashcards · Statistical modelling · Data tracking · In progress

Overview

FlashApp is designed around three main functions, with the goal of making studying more efficient and more measurable.

1. Decks

Create different slide decks, rate them, and add, remove or edit questions and their detail.

2. Practice mode

Pick a deck and work through it. For each flashcard you see the question, click to reveal the answer, then rate how you did:

  • Too easy
  • Correct, but could use improvement
  • Incorrect
  • No clue

Each rating is recorded along with the user who answered.

3. Review mode

A statistical model considers when you last saw each question and how hard you found it, then picks the questions to review for the best recall and learning. You choose which decks to include before you start, and your ratings carry over.

Data tracked

The app records as much as possible, including how long you spend on each flashcard, measured between clicks.

Skills shown

Application design, statistical modelling, data collection and user-experience design.

Overview

MindTheAI is a Chrome extension built at the CMD-F 2026 hackathon to help people use AI tools more thoughtfully and more safely.

What it does

  • Password protection, so sensitive details stay out of AI prompts
  • Removes personal data and prompt filler before a prompt is sent
  • Flags unreliable sources
  • Usage reminders that nudge users to rethink unnecessary prompts
  • Helps users understand the impacts of AI usage

Result

Won the 1Password sponsor prize for the best integration of security practices into a coding project. Winners received $100 and 1Password subscriptions.

Skills shown

Browser extension development, privacy and security thinking, and rapid prototyping with a team.
